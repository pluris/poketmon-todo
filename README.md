# Pleco

> 아이의 오늘 할 일이, 몬스터의 내일이 된다.

8세 아이가 스스로 할 일을 해내고, 그 노력으로 오리지널 몬스터를 키우는 키즈 라이프 게임입니다.
아이용 PWA와 엄마용 PWA를 각각 설치할 수 있습니다.

## 지금 되는 것 (M0)

### 아이용 PWA `/kid`
- 이름 입력 → 시작 알 선택 → 몬스터 이름 짓기
- 몬스터 돌봄: 밥 / 놀이 / 씻기 / 쉬기
- 상태 4종: 포만감 · 기분 · 청결 · 기력 (수면 시간에는 감소 정지)
- 오늘의 할 일 확인, 완료, 엄마 확인 대기
- XP · 레벨 · 친밀도 · 훈련 능력치(힘/지혜/마음)
- Lv.5 + 친밀도 30 → 훈련 능력치에 따라 3가지 모습으로 진화
- 도감: 진화 계보, 실루엣, 훈련 현황
- 3종 몬스터 라인 × 3 진화 분기

### 엄마용 PWA `/parent`
- 4자리 PIN 설정 / 잠금
- 오늘의 진행률과 아이 몬스터 상태
- 완료 미션 승인 / 다시 하기
- 미션 만들기: 이름, 아이콘, 능력치, 난이도, 매일/오늘만, 엄마 확인 여부
- 미션 삭제, PIN 변경, 데이터 초기화

### 공통
- 로컬 저장(localStorage) + 같은 브라우저 탭 간 자동 동기화
- PWA 매니페스트 · 아이콘 · 서비스 워커
- 모바일/태블릿 우선 반응형 UI
- 광고 · 결제 · 외부 링크 없음

## 실행

```bash
npm install
npm run dev
```

- 아이 앱: http://localhost:3000/kid
- 엄마 앱: http://localhost:3000/parent

## 검증

```bash
npm test        # 게임 규칙 테스트 (Vitest)
npm run typecheck
npm run build
```

## PWA로 설치

HTTPS 또는 localhost에서 열어야 설치할 수 있습니다.

1. 태블릿에서 `/kid`를 열고 브라우저 메뉴 → **홈 화면에 추가**
2. 엄마 폰에서 `/parent`를 열고 브라우저 메뉴 → **홈 화면에 추가**
3. 두 앱은 같은 코드베이스지만 `manifest`의 `id`/`start_url`/`scope`가 달라 각각 설치됩니다.

## 게임 규칙 요약

| 항목 | 규칙 |
|---|---|
| 할 일 카테고리 | 운동 → 힘 / 공부·독서 → 지혜 / 정리·친절 → 마음 |
| 보상 | 쉬움 10 XP·5 코인 / 보통 20·10 / 어려움 30·15 |
| 레벨업 | 필요 XP = `10 + level × 10` |
| 진화 | Lv.5 + 친밀도 30, 가장 많이 훈련한 능력치로 분기 (동률이면 마음) |
| 돌봄 | 밥 5코인, 놀이·씻기·쉬기 무료, 스탯 하한 20 |
| 오프라인 | 최대 24시간까지만 스탯 감소, 21시~7시 정지 |
| 친밀도 | 할 일 완료 +1, 돌봄 +1 (스탯이 90 미만일 때만) |

## 알려진 제한

- **엄마 폰 ↔ 아이 태블릿 실시간 동기화는 아직 없습니다.** 현재는 같은 브라우저(같은 기기)의 탭끼리만 동기화됩니다. 다음 단계에서 가족 코드 + Supabase로 연결할 예정입니다.
- 엄마 PIN은 기기 로컬 잠금입니다. 서버 인증이 아니므로 중요한 개인정보를 보관하지 않습니다.
- 사진 인증, 타이머, 주간 리포트, 교배/알 부화, 탐험은 다음 마일스톤입니다.
