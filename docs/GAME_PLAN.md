# Pleco (가칭) — 키즈 할 일 × 몬스터 육성 게임 기획서 v0.1

> 아이의 오늘 할 일이, 몬스터의 내일이 된다.

---

## 0. 확정 사항 (2026-11-26)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 PWA (태블릿 우선) |
| IP | 오리지널 몬스터 (추후 확장) |
| 대상 | 8세 아이 |
| 앱 구성 | **아이용 PWA** + **엄마용 PWA** (별도 설치 화면) |
| 엄마 앱 역할 | 오늘의 미션/할 일 설정, 완료 승인, 아이 상태 확인 |
| 동기화 | 1차: 같은 기기 로컬 동기화 → 2차: 가족 코드 + Supabase |
| 구현 순서 | 아이 앱 코어 루프 → 엄마 앱 → 클라우드 동기화 |

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 키즈 라이프 관리 + 육성/수집 |
| 대상 | 8세 아이와 부모 (1차), 6~10세 확장 |
| 플랫폼 | 태블릿/폰 우선 웹 PWA (추후 네이티브 앱) |
| 세션 | 하루 5~15분, 짧게 여러 번 |
| 핵심 루프 | 할 일 완료 → 보상 → 돌봄 → 성장/진화 → 새 목표 |
| 차별점 | 실제 생활 습관이 몬스터의 능력치와 **진화 방향**을 결정 |

### 한 줄 정의
아이가 자기 할 일을 해내면, 그 노력이 몬스터의 밥과 경험치가 되어 함께 자라는 게임.

---

## 2. 목표와 디자인 원칙

### 아이
- 스스로 계획하고 완수하는 경험
- 성취가 눈에 보이는 성장으로 이어지는 감각
- 몬스터와의 정서적 애착

### 부모
- 매일 1분 안에 승인과 격려
- 아이와 함께 축하하는 도구
- 루틴 변화를 확인하는 주간 리포트

### 게임
- 다마고치의 돌봄/애착
- 포켓몬의 진화/수집/교배
- 아이가 주도하는 선택

### 5가지 원칙
1. **실패로 잃는 것은 없다** — 죽음, 굶주림, 연속 기록 소실 없음
2. **보상은 뇌물이 아니라 축하** — 결과보다 노력과 과정을 칭찬
3. **모든 조건은 눈에 보인다** — 진화 체크리스트, 다음 목표 안내
4. **아이가 결정한다** — 이름, 진화 시점, 놀이 선택, 꾸미기
5. **부모는 심판이 아니라 코치** — 승인 + 함께하기 + 회고

## 3. 코어 루프

```
[할 일 완료] → [XP/코인/아이템] → [돌봄] → [친밀도/기분] → [진화] → [새 목표]
      ↑                                                              │
      └──────────────────────────────────────────────────────────────┘
```

### 하루 루프 (5~10분)
1. **아침**: 오늘의 할 일 확인 (그림 카드)
2. **완료**: 체크 → 부모 승인(설정 시) → 보상
3. **돌봄**: 밥/놀이/씻기/잠 → 기분 회복, 친밀도 상승
4. **저녁**: 오늘의 성장 카드, 내일 할 일 미리보기

### 성장 루프 (1~2주)
- XP → 레벨 → 진화 조건 → 진화 연출 → 도감 등록
- 훈련 능력치(힘/지혜/마음)가 진화 분기를 결정

### 수집 루프 (1~3개월)
- 성체 2마리 → 알 돌보기 → 부화 → 유전 형질 확인 → 새로운 조합
- 도감/배지/하비타트 꾸미기

## 4. 시스템 설계

### 4.1 할 일 (자기관리)

**템플릿**: 양치, 옷 입기, 숙제, 독서, 정리, 운동, 준비물, 칭찬/친절

| 항목 | 내용 |
|---|---|
| 유형 | 매일 / 요일별 / 주간 / 한 번 |
| 검증 | 신뢰(체크만) / 부모 승인 / 타이머 / 사진(로컬 저장) |
| 난이도 | 쉬움 10 XP·5 코인 / 보통 20·10 / 어려움 30·15 |
| 보너스 | 오늘 첫 완료 +10 XP, 주 5일 달성 배지 |

**카테고리 → 훈련 능력치** (핵심 차별점)
- 운동/야외 → **힘**
- 공부/독서 → **지혜**
- 정리/도움/친절 → **마음**

아이의 실제 행동이 몬스터의 성장 방향을 만든다.

**자기관리 장치**
- 아이가 오늘의 할 일 3개를 직접 고르기
- 완료 후 스스로 체크, 부모는 승인
- 주간 회고 카드: "이번 주 내가 잘한 것"
- 내일 미리보기로 계획 습관 형성
- 글 읽기 전 아동을 위한 그림 카드 + 음성 안내(추후)

### 4.2 경제

| 재화 | 역할 | 획득 | 사용 |
|---|---|---|---|
| XP | 성장 | 할 일, 탐험 | 레벨업 |
| 코인 | 소비 | 할 일, 탐험, 미니게임 | 음식, 장난감, 꾸미기 |
| 아이템 | 돌봄/진화 | 할 일, 탐험, 이벤트 | 밥, 위생, 진화의 돌 |
| 친밀도 | 장기 애착 | 돌봄, 할 일 | 진화 조건 |

- 하루 코인 상한 200 (초과분도 XP/친밀도는 지급 → 노력은 항상 인정)
- **현금 결제, 가챠, 광고 없음**
- 아이템은 놀이를 대체하지 않고 확장만 한다

### 4.3 돌봄 (다마고치)

| 스탯 | 의미 | 감소 | 회복 |
|---|---|---|---|
| 포만감 | 배고픔 | -2/h | 밥, 간식 |
| 기분 | 놀이/애정 | -1/h | 놀이, 쓰다듬기 |
| 청결 | 위생 | -1/h | 씻기 |
| 기력 | 활동 | -1/h | 잠, 휴식 |
| 친밀도 | 장기 애착 | 없음 | 돌봄, 할 일 |

- 오프라인 감소는 최대 24시간, **하한 20** → 오래 자리를 비워도 죽지 않음
- 수면 모드(기본 21:00~07:00)에는 감소 정지
- 기분 상태: 신남 / 평온 / 심심 / 삐침 / 졸림 → 표정·대사·모션만 변화
- 대사는 죄책감 유발 금지: "배고파요" (O), "너 때문에 아파요" (X)
- 쓰다듬기/말걸기는 무료, 쿨다운 5분

### 4.4 성장과 진화 (포켓몬)

**단계**: 알 → 아기 → 어린이 → 청소년 → 어른 → 각성(선택)

**조건 유형**
- 레벨, 친밀도, 돌봄 점수, 아이템, 시간대
- 훈련 능력치(힘/지혜/마음)
- 할 일 카테고리 누적, 탐험 횟수

**분기 예시**
```
물방울(아기) ──Lv5──▶ 방울이(어린이)
                         ├─ 힘 우세   → 물결치
                         ├─ 지혜 우세 → 안개솜
                         └─ 마음 우세 → 이슬비
```

- 진화 힌트 카드: 체크리스트 + 실루엣, 최종형은 비공개 가능
- 진화 연출: 5초 풀스크린, 도감 등록, 기념 카드
- **진화 거부(영원의 돌)**: 아이가 원할 때까지 보류 가능
- 진화해도 이름/친밀도는 유지

### 4.5 교배와 알 돌보기

- **해금**: 성체 2마리 + 레벨 20 + 보금자리 아이템
- **궁합**: 알그룹(들풀/물가/숲) + 친밀도 → 확률
- **과정**: 두 친구를 보금자리에 → 알 생성 → 할 일 완료로 온기 10%씩 → 부화
- **유전**: 종(한쪽), 능력치 유전자 2~3개, 성격, 특성 1개, 희귀 색 변이
- 형제/근친 방지 플래그
- 최대 12마리, 방생은 "새 친구를 만나러 갔어요" 긍정 프레이밍
- **연령 고려**: 5~7세는 "알 돌보기" 모드로 단순화, 부모 설정으로 끄기 가능
- 유료 알/가챠 없음

### 4.6 탐험과 미니게임

- **탐험**: 30분 / 2시간 / 8시간, 오늘 할 일 1개 완료 시 출발
- 보상: 코인, 아이템, 알 조각, 엽서 스토리
- 실패 없음: 길을 잃어도 무사히 귀환, 보상만 적음
- 미니게임 3종: 먹이 잡기, 거품 터뜨리기, 기억 카드
- 하루 플레이 제한, 광고/가챠 없음
- 배틀은 v2 이후 선택 사항 (MVP 제외)

### 4.7 도감과 배지

- 실루엣 도감, 진화 계보, 획득 기념 카드
- 배지: 첫 진화, 7일 함께, 독서 10회, 알 부화 등
- 공유는 이미지 저장만 (SNS/채팅 없음)

### 4.8 몬스터 예시 (콘텐츠 확장용)

| 속성 | 돌봄 특징 | 플레이 성격 |
|---|---|---|
| 불 | 기력 소모 빠름, 밥 많이 먹음 | 빠른 성장 |
| 물 | 청결 민감, 씻기 좋아함 | 안정적 |
| 풀 | 낮 시간 보너스 | 느긋함 |
| 빛 | 친밀도 성장 빠름 | 애정 중심 |
| 바람 | 놀이/탐험 보너스 | 활동적 |
| 돌 | 오프라인 내성 | 느리지만 단단함 |

## 5. 성장 곡선 (첫 7일)

| 날 | 경험 |
|---|---|
| 1일 | 알 부화, 튜토리얼 할 일 3개, 첫 밥 |
| 2일 | 레벨 3, 놀이 해금, 첫 아이템 |
| 3일 | 청결/수면 해금, 첫 배지 |
| 4일 | 진화 힌트 공개, 훈련 능력치 확인 |
| 5일 | **첫 진화** (Lv5 + 친밀도 30) |
| 7일 | 주간 리포트, 새 알/탐험 예고 |

- 첫 진화는 3~5일 안에 → 초반 이탈 방지
- 교배는 2~3주 차 → 장기 목표
- 하루 목표: 할 일 3개 + 돌봄 2회 (5~10분)

## 6. 부모 모드와 안전

- **PIN 게이트** (아이가 추측하기 어려운 4자리)
- 승인 큐: 하루 1분
- 할 일 템플릿, 보상 배율(0.5~2x), 조용한 시간, 화면 시간
- 주간 리포트: 완료율, 돌봄, 기분, 진화
- 데이터: 기본 로컬 저장, 내보내기/삭제
- 개인정보 최소화: 아이 실명/생년월일 미수집, 닉네임/아바타만
- 광고/채팅/외부 링크/결제 없음
- 아동 개인정보 보호(COPPA/GDPR-K/국내 법령) 검토 및 부모 동의
- 카피 톤: 비난/죄책감/손실 회피 없음

## 7. 화면 구성

### 아이용 PWA (`/kid`)
1. **온보딩**: 이름 → 시작 알 선택 → 몬스터 이름 짓기
2. **홈(하비타트)**: 몬스터, 상태, 돌봄 버튼, 오늘의 할 일
3. **할 일**: 그림 카드, 체크, 승인 대기, 타이머
4. **도감**: 진화 계보, 실루엣, 훈련 능력치
5. **진화 연출**: 풀스크린 축하 + 도감 등록

### 엄마용 PWA (`/parent`)
1. **PIN 설정/잠금**: 4자리, 아이와 분리된 화면
2. **오늘**: 승인 대기, 오늘의 진행률, 아이/몬스터 상태
3. **할 일 관리**: 미션 추가(오늘만/매일), 삭제, 보상 미리보기
4. **설정**: PIN 변경, 데이터 초기화, 동기화 상태

### 공통
- 두 앱은 같은 코드베이스에서 **각자의 manifest/start_url**로 설치
- 1차 버전은 같은 브라우저 저장소를 공유해 로컬 동기화
- 2차 버전은 가족 코드로 엄마 폰 ↔ 아이 태블릿 실시간 동기화

## 9. 기술 설계 (권장안)

- **스택**: Next.js + TypeScript + Tailwind + Zustand + Dexie(IndexedDB) + Framer Motion + Howler
- **PWA**: 오프라인 동작, 홈 화면 설치, Vercel 배포
- **두 개의 설치형 PWA**: `/kid`와 `/parent`가 각각 manifest/start_url을 가짐
  - 같은 코드베이스, 같은 도메인, 같은 로컬 저장소
  - 2차에서 가족 코드 기반 Supabase 동기화 추가
- **도메인 분리**: `src/game`에 순수 규칙
  - `tick`, `completeTask`, `care`, `canEvolve`, `evolve`, `breed`, `hatch`
- **콘텐츠 분리**: `src/content`에 JSON (species, evolution, items, templates)
- **결정론적 RNG + 주입 가능한 시계** → 시뮬레이션 테스트 가능
- **테스트**: Vitest(규칙), Playwright(플로우), 30일 시간여행 테스트
- **저장**: 버전 스키마 + 마이그레이션 + JSON 내보내기/가져오기
- **동기화(2단계)**: Supabase, 부모 이메일 + 가족 코드
- **아트**: SVG 레이어(몸/눈/액세서리) + 팔레트 변형
  - 6종 × 3단계 = 18스프라이트로 시작
- **사운드**: 잔잔한 루프, 켜기/끄기
- **접근성**: 48px 터치, 그림 중심, 색약 팔레트, 모션 감소
- **i18n**: 한국어 우선, 영어 확장 구조

## 10. MVP 범위

### 포함
- 아이 1명, 몬스터 1마리, 알 → 3단계, 6종 계열
- **아이용 PWA**: 온보딩, 홈, 할 일, 돌봄, 진화, 도감
- **엄마용 PWA**: PIN, 미션/할 일 추가, 승인, 진행률
- 할 일 템플릿/커스텀, 매일/오늘만, 부모 승인
- 돌봄 4스탯 + 4행동, 기본 아이템
- 레벨 + 친밀도 + 훈련 분기 진화
- 로컬 저장(같은 기기 동기화), PWA, 한국어
- 간단한 알 돌보기(교배-lite): 성체 2마리 → 알 → 할 일로 부화

### 제외
- 클라우드/멀티 자녀
- 탐험, 미니게임 다수
- 하비타트 꾸미기, 시즌 이벤트
- 배틀
